# Asteroids
## Asteroids™ - 3D Solar System &amp; Asteroids Simulator (UWP)
The Asteroids™ application lets you monitor the positions and trajectories of all known asteroids in our Solar System. To do this, it continuously calculates and updates the orbits of more than 1.5 million asteroids using data from NASA’s Jet Propulsion Laboratory. For Near-Earth Objects (NEOs), the data is aligned with the Center for Near-Earth Object Studies (CNEOS).
